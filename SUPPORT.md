# Getting help

1. **Read the [README](README.md)**, then the plugin repository linked from it.
2. **Ask in [Discussions](https://github.com/Viprasol-Tech/claude-plugins/discussions)**
   for how-to questions and to share what you built.
3. **Open an [issue](https://github.com/Viprasol-Tech/claude-plugins/issues)** about this
   marketplace (a broken install line or link). Bugs in a plugin belong in its own repository.
4. **Need a trading system, fintech platform or voice agent built?** Viprasol Tech does this
   professionally: [viprasol.com](https://viprasol.com) · [support@viprasol.com](mailto:support@viprasol.com).
