# Security policy

This repository only lists plugins; their code lives in the linked
repositories. Report a problem in a plugin privately through that
repository's security advisories, or a problem with this marketplace through
[GitHub security advisories](https://github.com/Viprasol-Tech/claude-plugins/security/advisories/new)
or [support@viprasol.com](mailto:support@viprasol.com). Do not open a public
issue. We aim to reply within 3 working days.
