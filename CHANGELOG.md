# Changelog

## [1.0.0] - 2026-11-24

### Added
- `viprasol` marketplace listing 7 plugins: trading-studio,
  tradingview-automation, crypto-bots, fintech-studio, india-stack,
  voice-agents and video-studio, each installed from its own repository with
  a `git-subdir` source.
- CI that validates the manifest and fetches every plugin's `plugin.json`
  from GitHub weekly.
